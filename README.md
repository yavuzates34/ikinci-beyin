# İkinci Beyin V3.2

Bu depo, yerel İkinci Beyin klasörünün GitHub'daki seçilmiş anlık görüntüsüdür.
Çalışan ajanlar dosyaları değiştirebildiği için GitHub içeriği eşitleme anındaki
durumu gösterir; canlı dosya sistemi değildir.

- [Bilgi dizini](knowledge/index.md): kalıcı ve kaynak bağlantılı konu notları.
- [Aktif konular](🔮%20850-Companion/Threads.md): süren işler ve sonraki adımlar.
- [Son oturum](🔮%20850-Companion/Last-Session.md): en son doğrulanan sonuçlar.
- [AI operatörlüğü canlı kütüphanesi](notes/ai-operatorlugu/README.md): kaynaklar ve çalışma notları.

`visibility: private` işaretli kişisel not GitHub görüntüsüne alınmaz.
Eski İkinci Beyin düzeni `ana` dalında korunur; bu deponun varsayılan dalı
V3.2 içeriğini gösterir.
