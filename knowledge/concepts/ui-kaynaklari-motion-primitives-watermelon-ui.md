# Motion Primitives ve Watermelon UI

## Kullanıcı kaynağı ve niyeti

Yavuz, 24 Eylül 2026'da iki Instagram ekran görüntüsü paylaştı. Görsellerde
"Motion Primitives — UI Animasyonları" ve "Watermelon UI — Landing Page UI"
başlıkları görünüyor. İkisini de beğendiğini ve kaydetmemizi istedi. Belirli
bir projede kullanma veya kurma kararı belirtmedi. Kaynak: Yavuz'un aynı
tarihli mesajı ve iki ekli görsel.

## Doğrulanan kaynaklar

- [Motion Primitives](https://motion-primitives.com/) animasyonlu arayüz
  bileşenleri sunar. [Resmî GitHub deposu](https://github.com/ibelick/motion-primitives)
  bileşenlerin Motion ve Tailwind CSS üzerine kurulduğunu, kopyalanıp
  uyarlanabildiğini ve açık kaynak olduğunu belirtiyor. 24 Eylül 2026'da
  incelendi.
- [Watermelon UI](https://ui.watermelon.sh/) React bileşenleri, animasyonlu
  etkileşimler, landing page blokları, panolar ve şablonlar sunar.
  [Resmî GitHub deposu](https://github.com/WatermelonCorp/watermelon-platform)
  platformun kaynak kodunu ve bileşen kataloğu yapısını yayımlıyor.
  24 Eylül 2026'da incelendi.

## İlişki ve durum

İkisi, [NameThatUI](namethatui-ui-terminoloji-kaynagi.md) ile farklı amaçlarda
tamamlayıcı olabilir: NameThatUI öğenin adını öğrenmeye; bunlar arayüz örneği
ve uygulama kodu bulmaya yarar. Bu olası kullanım ilişkisi bir çıkarımdır.
İkisi de ajan `SKILL.md` becerisi değildir. Yalnız kaynak olarak
[kataloğa](../../.agents/skills/KATALOG.md) kaydedildi; kurulum yapılmadı.
